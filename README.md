# Smart-Attendance-System-using-Face-Recognition-and-Indoor-Based-Geo-Fencing-
📖 Project Description

The Smart Attendance System using Face Recognition and Indoor Based Geo-Fencing is an intelligent attendance management solution designed to automate and secure the traditional attendance process. The system combines Artificial Intelligence (AI), Face Recognition Technology, and Indoor Geo-Fencing to ensure accurate and fraud-free attendance marking.

This project helps educational institutions and organizations maintain attendance records efficiently without manual intervention. The system captures the user’s face through a webcam or mobile camera and verifies identity using face recognition algorithms. Additionally, indoor geo-fencing verifies whether the user is physically present within the authorized location before attendance is marked.

The project reduces proxy attendance, saves time, improves accuracy, and maintains digital attendance records securely in a database.
